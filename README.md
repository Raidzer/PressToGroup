# PressToGroup

Компактный помощник поиска заранее собранных групп для Mythic+ в World of Warcraft Retail.

## Статус

Проект находится на этапе согласования первой версии. Игровая реализация ещё не готова.

Аддон разрабатывается с нуля на штатном WoW API. Код и ресурсы Key Scout не используются.

## Первая версия

- Поиск и подача заявок от реальных нажатий игровых кнопок.
- Приоритет свежих подходящих групп и замена заявок без ответа через 3 минуты.
- Фильтры подземелий, роли, рейтинга лидера, языков и состава группы.
- Русский и английский интерфейс; отдельный выбор языков поиска.
- Компактное окно с состоянием поиска и очереди заявок.

Уровень ключа задаётся игроком в защищённой штатной строке поиска. Работа LFG-действий из игровых нажатий, в том числе в бою, должна пройти проверку в клиенте.

Подробности и критерии приёмки — в [черновике спецификации](docs/spec.md). Термины — в [CONTEXT.md](CONTEXT.md).
